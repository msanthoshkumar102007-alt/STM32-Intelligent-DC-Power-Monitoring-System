# Intelligent DC Power Monitoring and Protection System for Defence Electronics

## Project Overview

The **Intelligent DC Power Monitoring and Protection System for Defence Electronics** is an embedded systems project developed using the STM32F401RE microcontroller and designed and simulated using Proteus Design Suite. The project focuses on monitoring DC electrical parameters in real time and providing automatic protection against abnormal voltage and current conditions, which are important for maintaining the reliability and safety of electronic equipment used in defence-related applications.

The system measures DC supply voltage using a voltage divider circuit and load current using an ACS712-20A Hall-effect current sensor. The analog signals generated by these sensing circuits are processed through the ADC channels of the STM32F401RE microcontroller. The measured voltage and current values are calculated and displayed continuously on a 16x2 LCD, enabling real-time observation of the electrical operating conditions.

To improve system reliability, an automatic protection mechanism is implemented to detect overvoltage, undervoltage, and overcurrent conditions. Whenever any measured parameter crosses its predefined safety threshold, the STM32 microcontroller activates a relay to disconnect the connected load. LED indicators provide visual notifications of normal operating conditions and different fault conditions.

The complete circuit, including sensor interfacing, LCD display, relay control, and LED indicators, is developed and tested virtually using Proteus Design Suite. This project demonstrates the application of embedded monitoring and protection techniques that can be relevant to DC-powered defence electronic equipment, communication systems, control units, and other critical electronic subsystems.

## Working Principle

The system continuously monitors the DC supply voltage and load current using dedicated sensing circuits. The STM32F401RE processes the sensor outputs and compares the measured values with predefined safety limits.

### 1. DC Voltage Measurement

The input DC voltage is connected to a voltage divider circuit, which scales down the voltage to a suitable level for the STM32 ADC input. The microcontroller reads the analog signal and calculates the actual DC input voltage using the voltage divider ratio.

### 2. Current Measurement

The ACS712-20A Hall-effect current sensor measures the current flowing through the connected load. It generates an analog output voltage proportional to the measured current. The STM32 reads this signal through its ADC and calculates the load current using the sensor sensitivity and zero-current reference voltage.

### 3. Real-Time Parameter Display

The calculated voltage and current readings are continuously updated on the 16x2 LCD. This allows the user to monitor the electrical operating conditions of the connected DC system.

### 4. Overvoltage Protection

When the input voltage exceeds the predefined maximum safety limit, the microcontroller identifies an overvoltage condition and activates the relay to disconnect the connected load.

### 5. Undervoltage Protection

When the input voltage drops below the predefined minimum safety limit, the system detects an undervoltage condition and activates the protection mechanism to disconnect the load.

### 6. Overcurrent Protection

When the measured load current exceeds the predefined maximum current limit, the STM32 detects the overcurrent condition and controls the relay to disconnect the load, preventing excessive current from affecting the connected electronic equipment.

### 7. LED Fault Indication

LED indicators provide visual information about the operating status of the system. Different indicators can be used to identify normal operation, overvoltage, undervoltage, and overcurrent conditions.
